機身有兩個 speech engine：Nuance VoCon（offline，內建喺 alpha2services）同 iFlytek。經反編譯 Alpha2Services-v1.1.7.3.20 證實：Nuance 呢邊 speech_initGrammar／startSpeechGrammar 係完全未實作嘅空 stub（method body 得一句 return-void），自訂詞彙一律唔會生效； 但呢邊有一個獨立、寫死喺 native code 嘅內建 grammar（下面呢個表），單靠 local recognition 就會 work，唔使雲端（Nuance 雲端伺服器已停用，但呢個內建 grammar 唔靠佢）。 單字容易 mis-parse（例如淨係講"wave"可能會 match 錯做 QA），建議用完整短句 （例如「wave your left hand」）。

⚠️ Confidence 門檻：反編譯證實 local recognition 嘅 confidence 分數要 ≥4500 先會直接接受（唔使等雲端）；低於呢個門檻會判 invalid、等雲端補完——但雲端已停用， 所以低於 4500 分嘅結果實際上會全部有去無回。想提高成功率：企近部機、慢慢講、 咬字清楚、減少背景噪音，呢啲都會直接影響 confidence 分數。

語音輸入三合一測試（同一句嘢，睇邊個功能有反應）

呢度3條係唔同嘅AIDL method，用**同一句輸入**一齊送出，方便你直接對比邊個先真係work：

  • 模擬講嘢（onSpeech dictation，未測試，SDK標咗 @Deprecated 但搵唔到原因）—— 如果work，結果會經返「ASR」card嘅「辨識結果」／「意圖分類」顯示（同真正講嘢一樣嘅path）
  • 語法式辨識（initSpeechGrammar → startSpeechGrammar）—— ⚠️ 已反編譯確認：Nuance binding 之下係空 stub，一定失敗；要撞到 iFlytek 嘅真身實作（com.iflytek.cloud.SpeechRecognizer），要自己先用上面 「中文 (iFlytek)」掣切換，未切嘅話呢個測試會直接回傳 backend 個 guard error。 strGrammar 確實語法格式仍未反查完整，會將你打嘅嘢原封不動送去
  • 文字語意理解（onTextUnderstand，⚠️ 已confirm冧咗）——約1ms就返、 冇觸發任何callback，需要雲端但雲端伺服器已停用，留低純粹做對比基準
